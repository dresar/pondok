# Dokumentasi Teknis PSB Pondok

Folder ini berisi dokumentasi teknis lengkap mengenai Models (Database Schema) dan Endpoints (URL/API) untuk setiap aplikasi dalam proyek PSB Pondok.

## Struktur Dokumentasi

### 1. Core App (`core`)
Aplikasi inti yang menangani profil website, konten statis, dan pengaturan global.
- [Dokumentasi Models](core_models.md)
- [Dokumentasi Endpoints](core_endpoints.md)

### 2. Users App (`users`)
Aplikasi manajemen pengguna, autentikasi, role, dan dashboard santri.
- [Dokumentasi Models](users_models.md)
- [Dokumentasi Endpoints](users_endpoints.md)

### 3. Admissions App (`admissions`)
Aplikasi pendaftaran santri baru (formulir dan data santri).
- [Dokumentasi Models](admissions_models.md)
- [Dokumentasi Endpoints](admissions_endpoints.md)

### 4. Admin Panel (`admin_panel`)
Aplikasi dashboard khusus untuk administrator dan staff.
- [Dokumentasi Models](admin_panel_models.md)
- [Dokumentasi Endpoints](admin_panel_endpoints.md)

### 5. Payments App (`payments`)
Aplikasi manajemen pembayaran dan verifikasi.
- [Dokumentasi Models](payments_models.md)
- [Dokumentasi Endpoints](payments_endpoints.md)

### 6. Blog App (`blog`)
Aplikasi manajemen artikel, berita, dan pengumuman.
- [Dokumentasi Models](blog_models.md)
- [Dokumentasi Endpoints](blog_endpoints.md)

### 7. Documents App (`documents`)
Aplikasi generator dokumen PDF dan Excel.
- [Dokumentasi Models](documents_models.md)
- [Dokumentasi Endpoints](documents_endpoints.md)
