# Dokumentasi Endpoints Aplikasi Admissions

Aplikasi `admissions` menyediakan endpoint publik untuk pendaftaran santri baru.

Base URL: `/admissions/` (asumsi, perlu dicek di root urls).

| URL Pattern | View Name | Deskripsi |
|-------------|-----------|-----------|
| `register/` | `register` | Halaman formulir pendaftaran santri baru. |
| `success/` | `success` | Halaman sukses setelah pendaftaran berhasil. |
