    Import Data Santri

    Upload file Excel atau CSV untuk mengimpor data santri secara massal.

    Petunjuk Import

    • File harus berformat Excel (.xlsx) atau CSV (.csv)
    • Baris pertama harus berisi header kolom
    • Kolom yang wajib: Nama Lengkap, NISN, Tempat Lahir, Tanggal Lahir, Jenis Kelamin
    • Kolom opsional: Nama Ayah, Nama Ibu, Alamat, No. HP, Email, Asal Sekolah, Kelas Terakhir, Status
    • Format tanggal: YYYY-MM-DD (contoh: 2024-01-15)
    • Jenis Kelamin: L (Laki-laki) atau P (Perempuan)
    • Status: pending, verified, accepted, atau rejected
