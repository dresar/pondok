📚 Tutorial Mail Merge dengan Excel

Panduan lengkap cara menggunakan Mail Merge di Microsoft Word dengan data Excel dari sistem

1 Persiapan

Software yang Diperlukan:

  • ✅ Microsoft Word (2010 atau lebih baru)
  • ✅ Microsoft Excel (opsional, untuk melihat data)
  • ✅ File Excel dari sistem (sudah di-download)

Data yang Tersedia di Excel:

File Excel berisi kolom-kolom berikut yang bisa digunakan di Mail Merge:

Data Identitas:

  • No_Pendaftaran, NISN
  • Nama_Lengkap, Nama_Panggilan
  • Tempat_Lahir, Tanggal_Lahir
  • Jenis_Kelamin, Agama

Data Alamat:

  • Alamat, Desa, Kecamatan
  • Kabupaten, Provinsi
  • Kode_Pos, Alamat_Lengkap

Data Orang Tua:

  • Nama_Ayah, NIK_Ayah
  • Nama_Ibu, NIK_Ibu
  • Pekerjaan, Pendidikan, dll

Data Sekolah:

  • Asal_Sekolah, NPSN_Sekolah
  • Kelas_Terakhir, Tahun_Lulus
  • Kelas_Diterima, dll

2 Download Data Excel

Langkah 1: Login ke Admin Panel

  1. Buka browser dan login ke Admin Panel
  2. Masuk ke menu "Export Data Excel" di sidebar

Langkah 2: Pilih Data yang Akan Di-download

Opsi A: Download Semua Data Santri
  • Klik tombol "Download Semua Data" di pojok kanan atas
  • File akan terdownload dengan nama: Data_Semua_Santri_YYYYMMDD.xlsx
Opsi B: Download Data Satu Santri
  • Cari santri yang diinginkan (bisa menggunakan search)
  • Klik tombol "Download Excel" pada baris santri tersebut
  • File akan terdownload dengan nama: Data_Santri_NISN_Nama.xlsx

⚠️ Penting!

Simpan file Excel di folder yang mudah diakses. Pastikan file tidak dibuka di Excel saat akan digunakan di Word (tutup dulu jika terbuka).

3 Membuat Template Word

Langkah 1: Buat Dokumen Word Baru

  1. Buka Microsoft Word
  2. Buat dokumen baru atau gunakan template yang sudah ada

Langkah 2: Tulis Konten Dokumen

Tulis konten dokumen seperti biasa. Di tempat-tempat yang ingin diisi data dinamis, biarkan kosong atau tulis placeholder seperti:

SURAT KETERANGAN

Yang bertanda tangan di bawah ini, menerangkan bahwa:

Nama          : [NAMA_LENGKAP]
NISN          : [NISN]
Tempat/Tgl Lahir : [TEMPAT_LAHIR], [TANGGAL_LAHIR_LENGKAP]
Alamat        : [ALAMAT_LENGKAP]

Adalah benar-benar siswa di [NAMA_PONDOK]...

Demikian surat keterangan ini dibuat untuk dapat dipergunakan sebagaimana mestinya.

Mahato, [TANGGAL_SEKARANG_LENGKAP]

[NAMA_PONDOK]

Catatan: Jangan khawatir dengan placeholder ini, nanti akan diganti otomatis saat Mail Merge.

4 Menggunakan Mail Merge

Langkah 1: Buka Tab Mailings

  1. Di Microsoft Word, klik tab "Mailings" di menu bar
  2. Pastikan dokumen template sudah siap

Langkah 2: Pilih Data Source (Excel)

  1. Klik "Select Recipients" → "Use an Existing List..."
  2. Browse dan pilih file Excel yang sudah di-download
  3. Klik "Open"
  4. Jika muncul dialog "Select Table", pilih sheet "Data Santri" (atau sheet pertama)
  5. Pastikan checkbox "First row of data contains column headers" tercentang
  6. Klik "OK"

Langkah 3: Insert Merge Fields

Sekarang saatnya mengganti placeholder dengan field dari Excel:

  1. Pilih lokasi di dokumen yang ingin diisi data
  2. Klik "Insert Merge Field" (di tab Mailings)
  3. Pilih field yang sesuai, contoh:
    • Klik di tempat [NAMA_LENGKAP] → Insert Merge Field → Pilih Nama_Lengkap
    • Klik di tempat [NISN] → Insert Merge Field → Pilih NISN

Tips: Field akan muncul seperti: «Nama_Lengkap», «NISN», dll. Field ini akan diganti dengan data sebenarnya saat preview atau print.

Langkah 4: Preview Hasil

  1. Klik "Preview Results" (di tab Mailings)
  2. Word akan menampilkan data santri pertama
  3. Gunakan tombol panah (← →) untuk melihat data santri lainnya
  4. Periksa apakah semua field sudah benar

Langkah 5: Finish & Merge

Setelah yakin semua sudah benar:

  1. Klik "Finish & Merge"
  2. Pilih salah satu opsi:
    • "Edit Individual Documents..." → Membuat dokumen Word baru dengan semua surat (1 dokumen per santri)
    • "Print Documents..." → Langsung print semua dokumen
    • "Send Email Messages..." → Kirim via email (jika ada kolom email)

💡 Rekomendasi: Pilih "Edit Individual Documents..." untuk review dulu sebelum print.

5 Tips & Trik

✅ Tips Formatting

  • Format Tanggal: Gunakan Tanggal_Lahir_Lengkap untuk format "15 Januari 2024"
  • Format Tanggal Pendek: Gunakan Tanggal_Lahir untuk format "15/01/2024"
  • Alamat Lengkap: Gunakan Alamat_Lengkap untuk alamat yang sudah digabung

✅ Tips Field Naming

  • Semua field menggunakan underscore (_) bukan spasi
  • Field name case-sensitive (huruf besar/kecil berpengaruh)
  • Contoh: Nama_Lengkap (benar), nama_lengkap (salah)

✅ Tips Multiple Records

  • Jika ingin membuat surat untuk beberapa santri, pastikan Excel berisi semua data
  • Mail Merge akan membuat 1 dokumen per baris data di Excel

✅ Tips Conditional Text

Jika ingin menampilkan teks berbeda berdasarkan kondisi:

  1. Klik "Rules" → "If...Then...Else..."
  2. Pilih field, kondisi, dan teks yang akan ditampilkan
  3. Contoh: Jika Jenis_Kelamin = "Laki-laki", tampilkan "Ananda", else tampilkan "Anandita"

6 Troubleshooting

❌ Problem: Field tidak muncul di daftar

Solusi:

  • Pastikan Excel sudah di-link dengan benar
  • Pastikan header row di Excel tidak ada spasi atau karakter khusus
  • Coba tutup dan buka kembali Word, lalu link ulang Excel

❌ Problem: Data tidak muncul (kosong)

Solusi:

  • Pastikan nama field di Word sama persis dengan header di Excel
  • Periksa apakah data di Excel ada (buka Excel dan cek)
  • Pastikan tidak ada spasi di awal/akhir field name

❌ Problem: Format tanggal salah

Solusi:

  • Gunakan Tanggal_Lahir_Lengkap untuk format lengkap
  • Atau format manual di Word: { MERGEFIELD Tanggal_Lahir \@ "dd MMMM yyyy" }

❌ Problem: Excel tidak bisa dibuka di Word

Solusi:

  • Pastikan Excel tidak sedang dibuka di aplikasi lain
  • Pastikan format file adalah .xlsx (bukan .xls)
  • Coba save Excel sebagai format .xlsx lagi
